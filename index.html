Current app

rRepoDocs keeps repository documentation close to the code.

Open Markdown files from GitHub, edit with a focused workspace, preview changes, inspect history, and publish public read-only snapshots when a document needs to be shared.

GitHub-backed
Documents stay in the repository workflow instead of drifting into a separate CMS.
Markdown-first
Write, preview, and manage docs without losing the simplicity of plain text.
Mobile-ready
A compact navigation model makes file browsing, editing, previewing, and account actions reachable.

Public previews

Share a saved Markdown snapshot without exposing the repo.

rRepoDocs sharing creates a public browser link for the current saved document version. The receiver only sees a read-only preview, and the owner can expire or revoke links.

01

Create

Choose an expiry and publish the saved Markdown snapshot.

02

Send

Share the generated link with anyone who needs to read the document.

03

Revoke

Review active public links and turn off access when the preview is no longer needed.
